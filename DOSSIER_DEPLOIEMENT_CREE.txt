🛠️ COMMANDES UTILES APRÈS DÉPLOIEMENT
================================================================================

Voir les logs:
  $ docker-compose logs -f api              # API
  $ docker-compose logs -f mysql            # MySQL
  $ docker-compose logs -f                  # Tous

Redémarrer les services:
  $ docker-compose restart                  # Tous
  $ docker-compose restart api              # API seulement
  $ docker-compose restart mysql            # MySQL seulement

Arrêter:
  $ docker-compose down

Redéployer (après mise à jour):
  $ git pull
  $ docker-compose build --no-cache
  $ bash deployments/deploy.sh production

Sauvegarder les données:
  $ docker exec hinneh_mysql mysqldump -u hinneh_user -p insights_ce > backup_$(date +%Y%m%d_%H%M%S).sql

Restaurer une sauvegarde:
  $ docker exec hinneh_mysql mysql -u root -p insights_ce < backup.sql
